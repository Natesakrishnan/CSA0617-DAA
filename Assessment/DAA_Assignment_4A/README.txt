These scripts implement, in Python, the algorithms designed as pseudocode
in Assignment 4A. They are for your own verification/learning only - the
assignment itself must be submitted as pseudocode (see its "Important
Instructions": programming code is NOT accepted as pseudocode).

Each file is self-contained and runnable (Python 3, no extra packages):

  task1_fractional_knapsack.py       -> Task 1: fractional knapsack (greedy)
  task2_job_sequencing.py            -> Task 2: job sequencing with deadlines
  task3_knapsack01.py                -> Task 3: 0/1 knapsack (DP)
  task4_word_break.py                -> Task 4: WordBreak, faulty + corrected
  task5_graph_algorithms.py          -> Task 5: Dijkstra / Bellman-Ford / Floyd-Warshall
  task6_energy_aware_scheduling.py   -> Task 6: energy-aware job scheduling (DP)

Run any file directly, e.g.:
  python3 task3_knapsack01.py

All scripts were tested and reproduce the same results as the hand-traced
desk-checks in DAA_Assignment_4A_Solution.docx (e.g. Task 3 -> max value 45,
items {Q,R}; Task 6 -> max value 200, jobs {J2,J5,J7,J8}).
